Step 1 — Check what's actually in the data directory:
bashsudo ls -la /home/jghattas/data/mariadb/
You'll likely see the mysql/ directory still there. Clear it properly:
bashmake fclean
sudo rm -rf /home/jghattas/data/mariadb
sudo rm -rf /home/jghattas/data/wordpress
make
Removing the whole directory (not just /*) ensures nothing is left behind.

Step 2 — While it's starting, watch mariadb logs in real time:
bashdocker logs -f mariadb
You should now see the full first-boot sequence:
[setup] First boot — initializing MariaDB...
[setup] Waiting for temporary server...
[setup] Server ready.
[setup] Database and users created.
[setup] Verifying users created:
User    Host
root    localhost
jghattas  %
[setup] Temporary server stopped.
[setup] Starting MariaDB...
If you still don't see First boot after the clean, run this to confirm the directory is truly gone before make:
bashsudo ls /home/jghattas/data/mariadb 2>&1
# Should say: No such file or directory

Step 3 — If it still loops, verify wordpress has the mysql client:
bashdocker exec wordpress which mysql
If it returns nothing, the mariadb-client package didn't install. Share your wordpress Dockerfile and we'll fix it.
